Virtual Icechunk

A short tutorial for the 2026 IOOS Hackathon

This tutorial gives you a quick overview of virtual Icechunk stores: what they are, how one gets built, and what to check before building one. During the hackathon you will mostly hand the actual work to a coding agent that has the ocean-icechunks-skills installed. Each chapter is a short slide deck. Click through it, or press S for the speaker notes.

Before you start: get set up

New to the hub? Work through JupyterHub Skills first (about 30 minutes):

  1. Log in to the JupyterHub
  2. Find your way around JupyterLab
  3. Start your coding agent: Claude Code, Codex or Antigravity, with your own subscription
  4. Git and GitHub, with an agent: log in once with gh, then let the agent run git for you
  5. The scratch bucket: cloud storage for test stores

Two quick wins (chapter 1)

  1. Open 306 TB in about a second. Bering Sea bottom temperature on the snow crab grounds, 1994–2015, from the HYCOM reanalysis. Open in Colab
  2. Make your own virtual store. Five NOAA NDVI files on AWS become one local Icechunk store. Open in Colab
