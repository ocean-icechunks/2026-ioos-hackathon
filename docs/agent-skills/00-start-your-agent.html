Start your coding agent

Install Claude Code, Codex or Antigravity, sign in with your own subscription, and add the ocean-icechunks skills.

In this hackathon you hand most of the work to a coding agent running in a hub terminal. Bring your own subscription. Any one of these works:

Agent Subscription Command
Claude Code Claude Pro or Max claude
OpenAI Codex ChatGPT Plus or Pro codex
Google Antigravity A Google account with Antigravity access agy

You install the agent once. It goes in ~/.local/bin, inside your home directory, so it is still there the next time your server starts, and after image updates. Your sign-in is saved there too.

Warning

The agent works in your name, with your subscription. It can read and change files in your home directory, and it asks before running commands it is not sure about. Read what it proposes before you say yes.

1 · Install

Open a terminal (File → New → Terminal).

On the workshop hub

The workshop image does not include a coding agent. Agents update themselves about once a week, so a copy built into the image would soon be out of date. Instead the image ships a small helper, install-user-tools, that runs each agent’s official installer into your home directory:

install-user-tools claude        # Claude Code  -> ~/.local/bin/claude
install-user-tools agy           # Antigravity  -> ~/.local/bin/agy
install-user-tools claude agy    # both

install-user-tools --list shows what it can install. It does not install Codex; for that, see the next section.

Then put ~/.local/bin on your path. The image does not do this yet, so without it you get “claude: command not found”. Run this once:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.profile && export PATH="$HOME/.local/bin:$PATH"

The first half fixes every new terminal (hub terminals read ~/.profile); the second fixes the one you are in.

Codex, or a hub without the helper

Use the agent’s own installer:

  • Claude Code
  • Codex
  • Antigravity
curl -fsSL https://claude.ai/install.sh | bash

Install it into your home directory. Without --prefix, it is installed somewhere that is wiped when your server restarts.

npm install -g --prefix ~/.local @openai/codex

The installer is served compressed, so --compressed is needed.

curl -fsSL --compressed https://antigravity.google/cli/install.sh | bash

Then open a new terminal, so it picks up ~/.local/bin, and check that the agent is there:

which claude    # or codex, or agy   -> /home/jovyan/.local/bin/...
TipGood to know
  • “Command not found” in a new terminal? Run the ~/.profile line above. If you have a ~/.bash_profile, bash reads it instead of ~/.profile: put export PATH="$HOME/.local/bin:$PATH" there.
  • Your home directory has a 20 GiB quota. Claude Code keeps several versions (about 230 MB in ~/.local/share/claude); Antigravity is about 280 MB. To see what is using space: du -sh ~/.local ~/.cache
  • Run the installers as yourself, not with sudo. They install into your home.

2 · Sign in

Installing gives you the software, not access: the image has no credentials. Start the agent once and sign in with your own account.

  • Claude Code
  • Codex
  • Antigravity
cd ~
claude

The first start asks you to pick a theme and a sign-in method. Choose Claude account with subscription. It prints a link: open it in your browser, sign in, and paste the code it gives you back into the terminal.

The hub has no browser of its own, so use the device-code flow:

codex login --device-auth

Open the link it prints, sign in with your ChatGPT account, and enter the code. Then start it:

cd ~
codex
cd ~
agy

On the first start, sign in with the Google account that has your Antigravity access. It prints a link: open it, sign in, approve, and paste the code back into the terminal.

When you see the agent’s prompt, type /exit to leave. You only needed it installed and signed in.

3 · Add the ocean-icechunks skills

The ocean-icechunks-skills teach your agent how to build, check and document virtual Icechunk stores. This installs them for all three agents at once:

git clone https://github.com/ocean-icechunks/ocean-icechunks-skills ~/ocean-icechunks-skills

for dir in ~/.claude/skills ~/.agents/skills ~/.gemini/config/skills; do
  mkdir -p "$dir"
  for skill in virtual-icechunk archive-to-cloud; do
    ln -sfn ~/ocean-icechunks-skills/skills/$skill "$dir/$skill"
  done
done

To update them later, run git -C ~/ocean-icechunks-skills pull.

4 · Start it where you work

An agent works in the folder you start it from. So always cd into your project first:

cd ~/my-project
claude        # or codex, or agy

The first time you start it in a new folder, it asks whether you trust the folder. Say yes for your own project folders.

Check that the skills loaded. Type /skills (in Claude Code or Codex) or / (in Antigravity) and look for virtual-icechunk. Or just ask: “What skills do you have for Icechunk?”
